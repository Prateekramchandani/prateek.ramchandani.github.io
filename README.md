## Publish with GitHub Pages (free)
1. Create a GitHub repository, for example `prateekramchandani.github.io`.
2. Upload `index.html` and `PrateekRamchandani_Resume.pdf`.
3. Go to repository Settings → Pages.
4. Choose deployment from the `main` branch and `/ (root)`.
5. Wait for the deployment and use the generated URL on applications.

No build step or paid hosting is required.
